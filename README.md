# Borozdov Signal

A theme from the Borozdov collection. Two faces — dark **Void**, a midnight precision
instrument, and light **Paper**, the same instrument in daylight. Crisp tight-tracked type,
hairline geometry and one acid-lime signal for action.

![Borozdov Signal in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/signal/main/screenshots/dark.png)

![Borozdov Signal in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/signal/main/screenshots/light.png)

## Principles

- **Darkness is the substrate.** Near-black surfaces in steps of carbon and graphite;
  hairline edges do the work shadows usually would.
- **One signal.** Acid lime fills what you act on — checked tasks, enabled toggles, the
  main button — and nothing else. Links are iris violet.
- **Precision type.** Inter in a low 400–600 band, tracked tight everywhere.
- **Machined corners.** 6px on controls, 12px on panels, pills for tags.

## Features

- Dark and light modes, following Settings → Appearance → Base color scheme
- Callouts as carbon cards with a hairline edge; the title in iris, pulse green, lime,
  teal or coral by type
- Code on a quiet panel with lime strings and violet keywords
- Tables with a rounded hairline frame and grid
- Quiet pill tags with no rim
- Quiet editing: no focus ring around the note, its title or form fields while you type;
  property names read as labels, not boxed fields
- Text colors meet WCAG contrast on both faces; the lime is kept for fills, with black on top
- The phone layout keeps the same colors and shapes
- No `!important`: every rule can be overridden with a CSS snippet

## Installation

**From the community directory:** Settings → Appearance → Themes → Manage, search for
**Borozdov Signal**, then **Install and use**.

**By hand:** download `manifest.json` and `theme.css` from the
[latest release](https://github.com/borozdov-obsidian-themes/signal/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Signal/`, then choose Borozdov Signal under
Settings → Appearance → Themes.
